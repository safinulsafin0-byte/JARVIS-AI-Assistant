# 🤖 JARVIS AI Assistant

<p align="center">

A local LLM-powered personal AI assistant, automation system, and software engineering agent.

Built with **Qwen2.5-7B + Ollama**, JARVIS combines LLM reasoning, tool execution, computer control, coding intelligence, memory, and autonomous workflows into a single AI system.

</p>


## 🚀 Overview

JARVIS is a locally running AI assistant designed to act as a personal AI agent capable of understanding tasks, interacting with the operating system, assisting with software development, managing workflows, and providing intelligent support.

Unlike a traditional chatbot, JARVIS integrates an LLM brain with external tools and agents, allowing it to perform real-world actions instead of only generating text.

# ⚙️ Installation


## Requirements

- Python 3.10+
- Ollama
- Qwen2.5-7B model
- Git


## Install Ollama Model

ollama pull qwen2.5:7b


Run JARVIS
python main.py
